# atelier-front — atelier générique

Atelier Nx (Bun, Angular) assisté par IA. Il génère des applications
extérieures, Angular de la coque aux pages, React pour la coque seulement.
Chaque produit vit dans sa propre racine, hors de l'atelier, et l'atelier ne
contient aucune donnée d'application. Sa direction est fixée par la charte
[`PROJECT_AUTHORITY.md`](./PROJECT_AUTHORITY.md).

## Guides du propriétaire

- [L'atelier](./docs/proprietaire/atelier.md) : installer le poste de travail,
  commandes courantes, versions de Node et de Bun, requalification des
  bibliothèques, Git, CI, PR automatiques et dépannage.
- [Créer une application](./docs/proprietaire/produit.md) : le parcours de
  l'idée à la page qui fonctionne, les commandes, la reprise après un échec et
  le dépannage.
- [Piloter les agents](./docs/proprietaire/agents.md) : choisir un rôle, prompts
  prêts à copier et contrôle de fin sans lire le code.

## Agents IA

[`AGENTS.md`](./AGENTS.md) est chargé automatiquement : il impose la lecture de
la charte et le choix d'un rôle dans le
[modèle opératoire](./docs/agents/operating-model.md).
